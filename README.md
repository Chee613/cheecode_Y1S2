## 📂 What's Inside?

Across each subject directory, you will find:

* **📖 Study Notes & Cheat Sheets:** High-yield markdown notes, complexity cheat sheets, mathematical symbol references, and networking breakdowns.
* **📝 Tutorials & Model Answers:** Step-by-step solutions for weekly tutorials and review sheets.
* **💻 Labs & Coursework Projects:** Production-ready Java data structure implementations, NetBeans projects (Grocery Store System, Course Manager), and practical labs.
* **📚 Past Year Papers (PYQ):** Exam questions and detailed solutions across multiple academic sessions (2016–2024).
* **🚀 Advanced Question Banks:** 100-Question Extreme Hard question sets with verified answer distributions for Machine Learning and Data Structures, plus CCNA practice assessments.
