Open this folder in NetBeans as a Java Application project.

Important layout:
- Java source files are in src\grocerystoresystem\
- inventory.txt stays in the project root
- supporting PDFs/Markdown files are in docs\

Main class:
- grocerystoresystem.GroceryStoreSystem

If NetBeans cannot find inventory.txt at runtime, make sure the run working directory is set to the project root.
