# Chapter 7 Revision Notes: SVM + GMM

## 1. Support Vector Machine Overview

**Support Vector Machine**, or **SVM**, is a supervised machine learning algorithm mainly used for **classification**.

The Week 9 lecture introduces SVM as a classifier derived from statistical learning theory and mentions applications such as object detection, image retrieval, text recognition, biometrics, and speech recognition. It also notes that SVM can be used for regression, but the lecture focuses on classification. 

Simple meaning:

```text
SVM tries to find the best boundary that separates classes.
```

Example:

```text
Class +1: Apple
Class -1: Orange
```

SVM tries to draw a boundary:

```text
+ + + +        |        - - - -
+ + + +        |        - - - -
```

The special thing about SVM is:

```text
SVM does not choose just any separating boundary.
SVM chooses the boundary with the largest margin.
```

---

# 2. Linear Discriminant Function

The SVM decision boundary is:

```text
wᵀx + b = 0
```

Where:

```text
x = input feature vector
w = weight vector
b = bias
wᵀx = dot product between w and x
```

If:

```text
x = [x1, x2]
w = [w1, w2]
```

Then:

```text
wᵀx = w1x1 + w2x2
```

So:

```text
wᵀx + b = w1x1 + w2x2 + b
```

The prediction rule is:

```text
f(x) = sign(wᵀx + b)
```

Meaning:

```text
wᵀx + b > 0  → predict +1
wᵀx + b < 0  → predict -1
wᵀx + b = 0  → point is on the boundary
```

---

# 3. Decision Boundary and Hyperplane

A **decision boundary** separates classes.

In SVM:

```text
wᵀx + b = 0
```

is the decision boundary.

Depending on the number of features:

| Number of features | Boundary name |
| -----------------: | ------------- |
|                  1 | point         |
|                  2 | line          |
|                  3 | plane         |
|        more than 3 | hyperplane    |

So:

```text
2D SVM boundary = line
3D SVM boundary = plane
many dimensions = hyperplane
```

Example in 2D:

```text
x2
^
|       +   +   +
|
|-------------------- decision boundary
|
|       -   -   -
+----------------------------> x1
```

Important:

```text
w controls the direction / tilt of the boundary.
b controls the shift / position of the boundary.
```

---

# 4. Margin

The **margin** is the empty space between the decision boundary and the closest points.

```text
+ class                         - class

+   +   +       |       -   -   -
          ↑     |     ↑
          |     |     |
       margin boundary margin
```

A small margin is risky:

```text
+ + + | - - -
```

A large margin is safer:

```text
+ + +       |       - - -
```

SVM wants:

```text
maximum margin
```

The lecture says maximizing the margin is good and that only support vectors matter while other training examples can be ignored. 

---

# 5. Support Vectors

**Support vectors** are the training points closest to the decision boundary.

```text
+ class                         - class

+   +   +                       -   -   -
        +       |       -
        ↑       |       ↑
 support vector | support vector
```

They are important because they control the position of the boundary.

If support vectors are removed:

```text
decision boundary may change
```

If non-support vectors are removed:

```text
decision boundary usually does not change much
```

This is exactly the idea tested in the Week 9 tutorial, where the red-circled points are support vectors. 

---

# 6. Distance from Point to Boundary

Distance from a point `x` to the decision boundary:

```text
distance = |wᵀx + b| / ||w||
```

Where:

```text
|wᵀx + b| = absolute value
||w|| = length of weight vector
```

If:

```text
w = [w1, w2]
```

Then:

```text
||w|| = √(w1² + w2²)
```

Example:

```text
w = [3, 4]
b = -10
x = [3, 1]
```

Step 1:

```text
wᵀx + b
= (3)(3) + (4)(1) - 10
= 9 + 4 - 10
= 3
```

Step 2:

```text
|wᵀx + b| = |3| = 3
```

Step 3:

```text
||w|| = √(3² + 4²)
      = √(9 + 16)
      = √25
      = 5
```

Step 4:

```text
distance = 3 / 5
         = 0.6
```

# 7. Maximum Margin Classifier

A **maximum margin classifier** chooses the separating boundary with the largest margin.

SVM uses three important lines:

```text
wᵀx + b = +1     positive margin line
wᵀx + b = 0      decision boundary
wᵀx + b = -1     negative margin line
```

Diagram:

```text
+ class

+   +   +
--------------------  wᵀx + b = +1
          |
--------------------  wᵀx + b = 0
          |
--------------------  wᵀx + b = -1

-   -   -

- class
```

The full margin is:

```text
ρ = 2 / ||w||
```

So:

```text
smaller ||w|| → larger margin
larger ||w|| → smaller margin
```

Therefore:

```text
maximize margin = minimize ||w||²
```

---

# 8. Hard-Margin SVM Mathematics

Hard-margin SVM assumes the data can be perfectly separated.

The hard-margin constraint is:

```text
yᵢ(wᵀxᵢ + b) ≥ 1
```

Where:

```text
xᵢ = training example i
yᵢ = label of training example i
yᵢ ∈ {-1, +1}
```

This single formula represents both classes.

## If `yᵢ = +1`

```text
(+1)(wᵀxᵢ + b) ≥ 1
```

So:

```text
wᵀxᵢ + b ≥ 1
```

Positive points must be on the positive side.

## If `yᵢ = -1`

```text
(-1)(wᵀxᵢ + b) ≥ 1
```

Divide by `-1` and flip the inequality sign:

```text
wᵀxᵢ + b ≤ -1
```

Negative points must be on the negative side.

---

# 9. Primal Optimization Problem

Hard-margin SVM solves:

```text
Minimize:
Φ(w) = ||w||² = wᵀw

Subject to:
yᵢ(wᵀxᵢ + b) ≥ 1
for all training examples
```

Meaning:

```text
Find w and b such that:
1. the margin is large
2. all training points are correctly classified
```

The lecture says this is a quadratic optimization problem with linear constraints and introduces a dual problem with Lagrange multipliers `αᵢ`. 

---

# 10. Dual Problem and Alpha

The dual form uses:

```text
α₁, α₂, ..., αₙ
```

Each training point has one alpha value.

Important meaning:

```text
αᵢ = 0  → point is not a support vector
αᵢ > 0  → point is a support vector
```

The weight vector can be written as:

```text
w = Σ αᵢyᵢxᵢ
```

The classifier can be written as:

```text
f(x) = sign(Σ αᵢyᵢxᵢᵀx + b)
```

The important part is:

```text
xᵢᵀx
```

This is a dot product.

This dot product is the key idea that leads to the **kernel trick**.

---

# 11. Soft-Margin SVM

Hard-margin SVM does not work well when data is noisy or overlapping.

Example:

```text
+ + + +          - - - -
+ + - +          - + - -
```

So we use **soft-margin SVM**.

Soft-margin SVM allows some margin violations using slack variables.

The soft-margin constraint is:

```text
yᵢ(wᵀxᵢ + b) ≥ 1 - ξᵢ
```

Where:

```text
ξᵢ = slack variable
ξᵢ ≥ 0
```

Meaning:

```text
ξᵢ measures how much point i violates the margin rule.
```

---

# 12. Meaning of Slack Variable `ξᵢ`

|  Slack value | Meaning                                    |
| -----------: | ------------------------------------------ |
|     `ξᵢ = 0` | correctly classified and outside/on margin |
| `0 < ξᵢ < 1` | correctly classified but inside margin     |
|     `ξᵢ = 1` | on decision boundary                       |
|     `ξᵢ > 1` | usually misclassified                      |

---

# 13. Soft-Margin Objective Function

Soft-margin SVM minimizes:

```text
1/2 ||w||² + C Σξᵢ
```

Meaning:

```text
1/2 ||w||²  → make margin large
C Σξᵢ       → punish margin violations / mistakes
```

---

# 14. C Parameter

`C` controls the cost of mistakes.

Memory:

```text
C = Cost of mistake
```

## Large `C`

```text
Large C = strict teacher
```

Effect:

```text
mistakes are expensive
model tries hard to classify training data correctly
smaller margin
possible overfitting
```

## Small `C`

```text
Small C = forgiving teacher
```

Effect:

```text
mistakes are cheaper
model allows more violations
larger margin
possible underfitting
```

If:

```text
C → ∞
```

then:

```text
mistakes become infinitely expensive
SVM behaves like hard-margin SVM if perfect separation exists
```

The tutorial asks this directly: when `C` is infinite, the optimal hyperplane, if it exists, completely separates the data. 

---

# 15. Kernel Trick

Linear SVM cannot solve all data patterns.

Example of nonlinear data:

```text
      + + +
   +         +
 +     - -     +
 +     - -     +
   +         +
      + + +
```

A straight line cannot separate this well.

The **kernel trick** allows SVM to create nonlinear boundaries.

Mapping idea:

```text
Φ: x → φ(x)
```

Meaning:

```text
map original input x into a higher-dimensional feature space
```

Kernel function:

```text
K(x, z) = φ(x)ᵀφ(z)
```

Meaning:

```text
kernel calculates the dot product in feature space
without explicitly computing φ(x)
```

Kernel SVM classifier:

```text
f(x) = sign(Σ αᵢyᵢK(xᵢ, x) + b)
```

The Week 9 lecture outline includes nonlinear SVM and the kernel trick. 

---

# 16. Common Kernel Types

| Kernel         | Formula            | Use                        |     |   |           |                             |
| -------------- | ------------------ | -------------------------- | --- | - | --------- | --------------------------- |
| Linear         | `K(x,z)=xᵀz`       | linear boundary            |     |   |           |                             |
| Polynomial     | `K(x,z)=(xᵀz+c)^d` | polynomial curved boundary |     |   |           |                             |
| Gaussian / RBF | `K(x,z)=exp(-      |                            | x-z |   | ²/(2σ²))` | flexible nonlinear boundary |

---

# 17. Gaussian / RBF Kernel

Gaussian kernel is also called RBF kernel.

Formula:

```text
K(x, z) = exp( - ||x - z||² / (2σ²) )
```

Where:

```text
x, z = two data points
||x - z||² = squared distance
σ² = sigma squared
```

Meaning:

```text
close points → K close to 1
far points → K close to 0
```

---

# 18. Meaning of `σ²`

`σ²` controls the width of Gaussian similarity.

## Small `σ²`

```text
small σ² → narrow influence
small σ² → flexible / wiggly boundary
small σ² → possible overfitting
```

## Large `σ²`

```text
large σ² → wide influence
large σ² → smoother boundary
large σ² → possible underfitting
```

---

# 19. Relationship Between `σ²` and `gamma`

In scikit-learn:

```python
SVC(kernel="rbf", gamma=...)
```

Relationship:

```text
gamma = 1 / (2σ²)
```

So:

| Lecture notation | Scikit-learn notation | Effect           |
| ---------------- | --------------------- | ---------------- |
| small `σ²`       | large `gamma`         | complex boundary |
| large `σ²`       | small `gamma`         | smooth boundary  |

```

In scikit-learn:

```

# 21. Feature Normalization Before Gaussian Kernel

Gaussian kernel depends on distance:

```text
||x - z||²
```

If one feature has a much larger scale, it dominates distance.

Example:

```text
salary = around 3000
age = around 20
```

Distance:

```text
(3000 - 4000)² + (20 - 25)²
= 1,000,000 + 25
```

Salary dominates. Age almost does not matter.

So before Gaussian kernel SVM, use scaling:

```python
from sklearn.preprocessing import StandardScaler
```

The tutorial asks why feature normalization is important before using Gaussian kernel, and this is the reason.

# 23. SVM Python Code Example

```python
import numpy as np
from sklearn.svm import SVC
from sklearn.preprocessing import StandardScaler
from sklearn.pipeline import make_pipeline
from sklearn.model_selection import train_test_split
from sklearn.datasets import make_moons

# Create nonlinear dataset
X, y = make_moons(
    n_samples=300,
    noise=0.25,
    random_state=42
)

# Split data
X_train, X_test, y_train, y_test = train_test_split(
    X, y,
    test_size=0.3,
    random_state=42
)

# RBF Kernel SVM
model = make_pipeline(
    StandardScaler(),
    SVC(kernel="rbf", C=1.0, gamma=1.0)
)

# Train
model.fit(X_train, y_train)

# Evaluate
print("Training accuracy:", model.score(X_train, y_train))
print("Test accuracy:", model.score(X_test, y_test))
```

Important:

```python
SVC(kernel="rbf", C=1.0, gamma=1.0)
```

Means:

```text
kernel="rbf" → use Gaussian / RBF kernel
C=1.0        → mistake penalty
gamma=1.0    → inverse of Gaussian width
```

# 24. Gaussian Mixture Model Overview

A **Gaussian Mixture Model**, or **GMM**, is a probabilistic clustering model.

Simple meaning:

```text
GMM assumes data comes from several Gaussian distributions.
```

The Week 9 lecture says GMM creates a new PDF, is a generative model, clusters components using Gaussian distribution, and provides soft assignment. 

Example:

```text
Gaussian 1 → short people
Gaussian 2 → medium-height people
Gaussian 3 → tall people
```

---

# 25. Gaussian Distribution

A Gaussian distribution is also called a normal distribution.

It looks like a bell curve:

```text
              μ
              |
              v
            _____
          /       \
        /           \
_______/             \_______
```

For 1D:

```text
N(x | μ, σ²)
```

Where:

```text
μ = mean / center
σ² = variance / spread
```

Small variance:

```text
narrow bell curve
```

Large variance:

```text
wide bell curve
```

---

# 26. GMM Formula

Main formula:

```text
p(x) = Σ πₖ N(x | μₖ, Σₖ)
       k=1 to K
```

Where:

```text
p(x) = probability density of x
K = number of Gaussian components
πₖ = mixing coefficient of component k
μₖ = mean of component k
Σₖ = covariance matrix of component k
N(x | μₖ, Σₖ) = Gaussian component k
```

The Week 12 recap also restates the GMM density formula using mixing coefficients and says GMM is a density estimator. 

---

# 27. GMM Parameters

The parameters to estimate are:

```text
πₖ, μₖ, Σₖ
```

For each Gaussian component `k`.

## Mixing coefficient `πₖ`

```text
πₖ = how much component k contributes
```

Rules:

```text
πₖ ≥ 0
Σπₖ = 1
```

Example:

```text
π₁ = 0.4
π₂ = 0.35
π₃ = 0.25
```

Valid because:

```text
0.4 + 0.35 + 0.25 = 1
```

## Mean `μₖ`

```text
μₖ = center of Gaussian component k
```

Example in 2D:

```text
μ₁ = [2, 3]
μ₂ = [8, 7]
```

## Covariance `Σₖ`

```text
Σₖ = spread, shape, and direction of Gaussian component k
```

In 1D:

```text
variance σ²
```

In multi-dimensional data:

```text
covariance matrix Σ
```

---

# 28. Hard Clustering vs Soft Clustering

## K-Means: hard clustering

```text
Point x belongs to Cluster 1 only.
```

Example:

```text
Cluster 1 = 1
Cluster 2 = 0
```

## GMM: soft clustering

```text
Point x belongs to each cluster with some probability.
```

Example:

```text
Cluster 1 = 0.70
Cluster 2 = 0.30
```

This is why GMM is called a soft clustering method.

---

# 29. Responsibility

In GMM, responsibility means:

```text
how much Gaussian k is responsible for data point xₙ
```

Notation:

```text
γₙₖ = P(zₙ = k | xₙ)
```

Formula:

```text
γₙₖ =
πₖ N(xₙ | μₖ, Σₖ)
-------------------------
Σⱼ πⱼ N(xₙ | μⱼ, Σⱼ)
```

Meaning:

```text
numerator = weighted probability from component k
denominator = total weighted probability from all components
```

Example:

```text
π₁ = 0.6
π₂ = 0.4

N₁(x) = 0.10
N₂(x) = 0.05
```

Weighted values:

```text
π₁N₁(x) = 0.6 × 0.10 = 0.06
π₂N₂(x) = 0.4 × 0.05 = 0.02
```

Total:

```text
p(x) = 0.06 + 0.02 = 0.08
```

Responsibilities:

```text
P(z=1 | x) = 0.06 / 0.08 = 0.75
P(z=2 | x) = 0.02 / 0.08 = 0.25
```

So:

```text
x belongs 75% to Gaussian 1
x belongs 25% to Gaussian 2
```

# 30. GMM and EM

GMM parameters are usually learned using **Expectation-Maximization**, or **EM**.

The lecture recap says maximum likelihood estimation of GMM has no closed-form solution and uses the EM algorithm. 

Basic idea:

```text
Initialize parameters
Repeat:
    E-step: calculate responsibilities
    M-step: update π, μ, Σ
Until convergence
```

Week 12 notes describe EM as a general algorithm for hidden variables: E-step computes posterior probability over `z`, and M-step updates Gaussian parameters to maximize the probability of the data.

# 33. GMM Python Code Example

```python
import numpy as np
from sklearn.mixture import GaussianMixture

# Simple 2D data
X = np.array([
    [1, 1],
    [1, 2],
    [2, 1],
    [8, 8],
    [8, 9],
    [9, 8]
])

# Create GMM with 2 Gaussian components
gmm = GaussianMixture(
    n_components=2,
    random_state=42
)

# Train model
gmm.fit(X)

# Hard cluster labels
labels = gmm.predict(X)

# Soft probabilities
probabilities = gmm.predict_proba(X)

print("Cluster labels:")
print(labels)

print("Soft probabilities:")
print(probabilities)

print("Means:")
print(gmm.means_)

print("Covariances:")
print(gmm.covariances_)

print("Mixing coefficients:")
print(gmm.weights_)
```

Important outputs:

```text
gmm.predict(X)       → hard cluster labels
gmm.predict_proba(X) → soft cluster probabilities
gmm.means_           → μ values
gmm.covariances_     → Σ values
gmm.weights_         → π values
```

# 34. Common Mistakes

## SVM Mistakes

### Mistake 1: Thinking SVM is unsupervised

SVM is supervised because it uses labels.

```text
xᵢ = input
yᵢ = label
```

### Mistake 2: Thinking all points matter equally

In SVM, support vectors matter most.

### Mistake 3: Forgetting feature scaling

SVM, especially Gaussian kernel SVM, is sensitive to feature scale.

### Mistake 4: Confusing `σ²` and `gamma`

```text
gamma = 1 / (2σ²)
```

So they move in opposite directions.

### Mistake 5: Thinking large `C` is always good

Large `C` can overfit.

---

## GMM Mistakes

### Mistake 1: Thinking GMM always beats K-Means

False.

### Mistake 2: Forgetting mixing coefficients

GMM parameters are not only `μ` and `Σ`.

They are:

```text
π, μ, Σ
```

### Mistake 3: Confusing hard and soft clustering

K-Means gives hard assignment.

GMM gives soft probabilities.

### Mistake 4: Giving covariance dimension wrongly

If:

```text
D = 3
```

one covariance matrix is:

```text
3 × 3
```

If:

```text
K = 3
```

all covariance matrices are:

```text
3 × 3 × 3
```

### Mistake 5: Confusing `N`, `D`, and `K`

```text
N = number of data points
D = number of dimensions/features
K = number of Gaussian components
```

# Chapter 7 Final Summary

## SVM

SVM is a supervised classifier that finds the best boundary between classes.

Main formula:

```text
wᵀx + b = 0
```

Prediction:

```text
f(x) = sign(wᵀx + b)
```

Main idea:

```text
Find the maximum-margin boundary.
```

Important terms:

```text
support vectors = closest important points
margin = safe space around boundary
C = mistake penalty
kernel = nonlinear similarity trick
σ² = Gaussian kernel width
```

---

## GMM

GMM is a probabilistic clustering model.

Main formula:

```text
p(x) = Σ πₖ N(x | μₖ, Σₖ)
```

Main parameters:

```text
πₖ = mixing coefficient
μₖ = mean
Σₖ = covariance
```

Main idea:

```text
GMM gives soft clustering probabilities.
```

K-Means says:

```text
Point x belongs to Cluster 1.
```

GMM says:

```text
Point x belongs:
70% to Cluster 1
30% to Cluster 2
```
