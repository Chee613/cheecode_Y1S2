# Chapter 6: Clustering and PCA

## 1. Big Picture

Chapter 6 has two main parts:

1. Clustering
2. PCA, Principal Component Analysis

Clustering is used to group similar data points.

PCA is used to reduce the number of features while keeping important information.

Simple relationship:

Original data
    ↓
Optional PCA
    ↓
Clustering

PCA can help clustering because clustering depends on distance. If there are too many noisy features, distance becomes confusing.

## 2. Clustering

```markdown
## 2.1 What is Clustering?

Clustering is an unsupervised machine learning technique that groups similar objects or data points into clusters.

Example:

Customer data:

Customer A = high spending, frequent visits
Customer B = high spending, frequent visits
Customer C = low spending, rare visits
Customer D = low spending, rare visits

Possible clusters:

Cluster 1: A, B
Cluster 2: C, D
```

The lecture says clustering groups similar objects or data points based on features, and the goal is to identify natural groupings, minimize distance within the same cluster, and maximize distance between different clusters. 

```markdown
## 2.2 Why Clustering is Unsupervised Learning

Clustering does not use labels.

Supervised learning:

X + y
features + correct answer

Clustering:

X only
features only

The algorithm tries to discover hidden groups by itself.
```

```markdown
## 3.1 Similarity

Similarity means how alike two data points are.

High similarity = more alike
Low similarity = less alike
```

```markdown
## 3.2 Dissimilarity / Distance

Dissimilarity means how different two data points are.

Small distance = more similar

```

The lecture lists **Euclidean distance**, **Manhattan distance**, and **Cosine similarity** as similarity/dissimilarity measures for clustering.

## 4. Euclidean Distance

```markdown
## 4.1 Meaning

Euclidean distance is straight-line distance between two points.
```

Formula:

```markdown
For A = (x1, y1)
and B = (x2, y2)

d(A, B) = √[(x2 - x1)² + (y2 - y1)²]
```

Example:

```markdown
A = (1, 2)
B = (4, 6)

d(A, B) = √[(4 - 1)² + (6 - 2)²]
        = √[3² + 4²]
        = √[9 + 16]
        = √25
        = 5
```

Python:

```python
import math

A = (1, 2)
B = (4, 6)

distance = math.sqrt((B[0] - A[0])**2 + (B[1] - A[1])**2)

print(distance)
```

Output:

```text
5.0
```

## 5. Manhattan Distance

```markdown
## 5.1 Meaning

Manhattan distance is like walking along city blocks.

You move horizontally and vertically, not diagonally.
```

Formula:

```markdown
d(A, B) = |x2 - x1| + |y2 - y1|
```

Example:

```markdown
A = (1, 2)
B = (4, 6)

d(A, B) = |4 - 1| + |6 - 2|
        = 3 + 4
        = 7
```

Python:

```python
A = (1, 2)
B = (4, 6)

distance = abs(B[0] - A[0]) + abs(B[1] - A[1])

print(distance)
```

Output:

```text
7
```

## 6. Cosine Similarity

```markdown
## 6.1 Meaning

Cosine similarity measures the angle between two vectors.

It focuses on direction, not only distance.
```

Formula:

```markdown
cos(θ) = (A · B) / (||A|| ||B||)
```

Where:

```markdown
A · B = dot product
||A|| = length of vector A
||B|| = length of vector B
```

Example:

```markdown
A = (1, 2)
B = (2, 4)

A · B = (1 × 2) + (2 × 4)
      = 2 + 8
      = 10

||A|| = √(1² + 2²)
      = √5

||B|| = √(2² + 4²)
      = √20

cos(θ) = 10 / (√5 × √20)
       = 10 / √100
       = 10 / 10
       = 1
```

Meaning:

```markdown
Cosine similarity = 1

A and B point in the same direction.
They are very similar.
```

Python:

```python
import numpy as np

A = np.array([1, 2])
B = np.array([2, 4])

cosine_similarity = np.dot(A, B) / (np.linalg.norm(A) * np.linalg.norm(B))

print(cosine_similarity)
```

# 7. K-Means Clustering

The lecture says K-Means partitions data into **K distinct clusters**, where K is chosen before running the algorithm. It also notes that K-Means works well for well-separated clusters but requires us to pre-specify K. 

```markdown
## 7.1 What is K-Means?

K-Means is a clustering algorithm.

K = number of clusters
Means = centroids / average points

If K = 2, the algorithm tries to divide data into 2 clusters.
```

```markdown
## 7.2 What is a Centroid?

A centroid is the center of a cluster.

Example:

A = (1, 1)
B = (3, 1)

Centroid:

x average = (1 + 3) / 2 = 2
y average = (1 + 1) / 2 = 1

Centroid = (2, 1)
```

---

## 8. K-Means Algorithm Steps

The lecture lists the K-Means steps as initialization, assignment, update, and convergence. 

```markdown
## 8.1 Step 1: Initialization

Choose K initial centroids.

Example:

K = 2

Initial centroids:
μ1 = (1, 1)
μ2 = (8, 8)
```

```markdown
## 8.2 Step 2: Assignment

Assign each point to the nearest centroid.

Rule:

Point goes to the cluster with the smallest distance.
```

```markdown
## 8.3 Step 3: Update

Recalculate each centroid using the mean of all points assigned to that cluster.
```

```markdown
## 8.4 Step 4: Convergence

Repeat assignment and update until centroids stop changing much.
```

---

## 9. Manual K-Means Example

```markdown
Data:

A = (1, 1)
B = (2, 1)
C = (8, 8)
D = (9, 8)

K = 2

Initial centroids:

μ1 = (1, 1)
μ2 = (8, 8)
```

### Assignment

```markdown
A is closest to μ1.
B is closest to μ1.
C is closest to μ2.
D is closest to μ2.

Cluster 1: A, B
Cluster 2: C, D
```

### Update

```markdown
Cluster 1:

A = (1, 1)
B = (2, 1)

new μ1 = ((1 + 2) / 2, (1 + 1) / 2)
       = (1.5, 1)

Cluster 2:

C = (8, 8)
D = (9, 8)

new μ2 = ((8 + 9) / 2, (8 + 8) / 2)
       = (8.5, 8)
```

Final:

```markdown
Cluster 1: A, B
Centroid 1: (1.5, 1)

Cluster 2: C, D
Centroid 2: (8.5, 8)
```

## 10. K-Means SSE / Inertia

```markdown
## 10.1 What is SSE?

SSE means Sum of Squared Errors.

In K-Means:

SSE = sum of squared distances between each point and its assigned centroid.
```

Formula:

```markdown
SSE = Σ distance(xᵢ, μc)²
```

Meaning:

```markdown
xᵢ = data point
μc = centroid of the cluster that xᵢ belongs to
Σ = add everything
```

Example:

```markdown
A = (1, 1)
B = (2, 1)

Centroid = (1.5, 1)

For A:

d² = (1 - 1.5)² + (1 - 1)²
   = (-0.5)² + 0²
   = 0.25

For B:

d² = (2 - 1.5)² + (1 - 1)²
   = 0.5² + 0²
   = 0.25

SSE = 0.25 + 0.25
    = 0.5
```

```markdown
Lower SSE = points are closer to centroids
Higher SSE = points are farther from centroids
```

Python:

```python
from sklearn.cluster import KMeans
import numpy as np

X = np.array([
    [1, 1],
    [2, 1],
    [8, 8],
    [9, 8]
])

kmeans = KMeans(n_clusters=2, random_state=0, n_init=10)
kmeans.fit(X)

print(kmeans.labels_)
print(kmeans.cluster_centers_)
print(kmeans.inertia_)
```

```markdown

Bottom-up.

Start with each point as its own cluster.

```

# 14. Linkage Methods

The Week 8 tutorial asks about **single linkage**, **complete linkage**, and **average linkage** as hierarchical clustering dissimilarity metrics. 

```markdown
## 14.1 Single Linkage

Distance between two clusters = smallest pairwise distance.

single = minimum distance
```

```markdown
## 14.2 Complete Linkage

Distance between two clusters = largest pairwise distance.

complete = maximum distance
```

```markdown
## 14.3 Average Linkage

Distance between two clusters = average of all pairwise distances.

average = sum of all pair distances / number of pair distances
```

Example:

```markdown
Cluster 1 = {A, B}
Cluster 2 = {C, D}

Distances:

A-C = 4
A-D = 7
B-C = 3
B-D = 8

Single linkage = min(4, 7, 3, 8)
               = 3

Complete linkage = max(4, 7, 3, 8)
                 = 8

Average linkage = (4 + 7 + 3 + 8) / 4
                = 22 / 4
                = 5.5
```

# 15. PCA

```markdown
## 15.1 What is PCA?

PCA means Principal Component Analysis.

PCA is an unsupervised dimensionality reduction technique.

It reduces many features into fewer new features called principal components.
```

The tutorial asks PCA questions about unsupervised learning, dimensionality reduction, PCA before clustering, and creating new features from the original feature set. 

```markdown
Before PCA:

x1, x2, x3, x4, x5

After PCA:

PC1, PC2
```

Important:

```markdown
PCA does not simply select old features.
PCA creates new features from combinations of old features.
```

---

## 16. Why Use PCA?

```markdown
PCA is useful for:

1. Reducing dimensionality
2. Removing some repeated or correlated information
3. Compressing data
4. Visualizing high-dimensional data
5. Sometimes helping clustering by reducing noisy dimensions
```

The lecture lists PCA advantages such as removing correlated features, speeding up other ML algorithms, and improving visualization, but also warns that normalization is required and valuable information may be lost.

# 17. PCA Main Idea

```markdown
PCA finds directions where data spreads the most.

Large spread = high variance
Small spread = low variance

PC1 = direction with the largest variance
PC2 = direction with the second largest variance
```

# 18. Mean Normalization

```markdown
## 18.1 Meaning

Mean normalization means subtracting the mean from each feature.

Formula:

x_centered = x - mean
```

Example:

```markdown
x = [2, 4, 6]

mean = (2 + 4 + 6) / 3
     = 4

x_centered:

2 - 4 = -2
4 - 4 = 0
6 - 4 = 2

Result:

[-2, 0, 2]
```

The tutorial states that even when features are on similar scales, mean normalization should still be performed before PCA. 

---

# 19. Feature Scaling

```markdown
Feature scaling makes features have comparable ranges.

Common formula:

x_scaled = (x - mean) / standard deviation
```

Use scaling when feature ranges are very different.

Example:

```markdown
Age: 18 to 60
Income: 1000 to 20000

Income may dominate PCA if we do not scale.
```

The tutorial states that if input features are on very different scales, feature scaling before PCA is a good idea.

# 20. Variance

```markdown
Variance means how spread out values are from the mean.
```

Formula:

```markdown
Var(x) = Σ(xᵢ - μ)² / m
```

Example:

```markdown
x = [2, 4, 6]

mean = 4

Differences:
-2, 0, 2

Squares:
4, 0, 4

Variance = (4 + 0 + 4) / 3
         = 8 / 3
         ≈ 2.67
```

---

# 21. Covariance

```markdown
Covariance tells whether two features move together.

Positive covariance:
x increases, y increases

Negative covariance:
x increases, y decreases

Near zero covariance:
no clear relationship
```

Formula:

```markdown
Cov(x, y) = Σ(xᵢ - μx)(yᵢ - μy) / m
```

Example:

```markdown
x = [1, 2, 3]
y = [2, 4, 6]

μx = 2
μy = 4

x_centered = [-1, 0, 1]
y_centered = [-2, 0, 2]

Multiply:
(-1)(-2) = 2
(0)(0) = 0
(1)(2) = 2

Sum = 4

Cov(x, y) = 4 / 3
          ≈ 1.33
```

---

# 22. Covariance Matrix

```markdown
A covariance matrix stores variances and covariances.

For two features x and y:

Σ = [ Var(x)    Cov(x,y) ]
    [ Cov(y,x)  Var(y)   ]
```

Example:

```markdown
Var(x) = 0.67
Var(y) = 2.67
Cov(x,y) = 1.33

Σ = [0.67   1.33]
    [1.33   2.67]
```

# 23. Eigenvector and Eigenvalue

```markdown
## 23.1 Eigenvector

In PCA:

Eigenvector = direction of a principal component
```

```markdown
## 23.2 Eigenvalue

In PCA:

Eigenvalue = amount of variance in that eigenvector direction
```

Key memory:

```markdown
Eigenvector = direction
Eigenvalue = importance / variance amount
```

Formula:

```markdown
Σu = λu
```

Where:

```markdown
Σ = covariance matrix
u = eigenvector
λ = eigenvalue
```

The tutorial asks that the first principal direction must be the **eigenvector** corresponding to the largest value/eigenvalue. 

```markdown
Largest eigenvalue → PC1
Second largest eigenvalue → PC2
Third largest eigenvalue → PC3
```

# 24. PCA Projection

```markdown
Projection means mapping original data onto principal component directions.

Formula:

z = x_centered · u
```

Where:

```markdown
z = projected lower-dimensional value
x_centered = original data after subtracting mean
u = principal component direction
```

Example:

```markdown
x_original = (4, 6)
mean = (2, 2)
u = [0.6, 0.8]

Step 1:

x_centered = (4, 6) - (2, 2)
           = (2, 4)

Step 2:

z = (2)(0.6) + (4)(0.8)
  = 1.2 + 3.2
  = 4.4
```

So:

```markdown
Projected value z = 4.4
```

---

# 25. Explained Variance Ratio

```markdown
Explained variance ratio tells how much total variance is captured by each principal component.
```

Formula:

```markdown
Explained variance ratio of PCᵢ = λᵢ / sum of all eigenvalues
```

Example:

```markdown
λ1 = 12
λ2 = 6
λ3 = 2

Total = 12 + 6 + 2
      = 20

PC1 ratio = 12 / 20 = 0.60 = 60%
PC2 ratio = 6 / 20  = 0.30 = 30%
PC3 ratio = 2 / 20  = 0.10 = 10%
```

Cumulative explained variance:

```markdown
PC1 only = 60%

PC1 + PC2 = 60% + 30%
          = 90%

PC1 + PC2 + PC3 = 100%
```

If we want at least 90% variance:

```markdown
Keep PC1 and PC2.
```

# 26. PCA Python Example

```python
import numpy as np
from sklearn.decomposition import PCA

X = np.array([
    [1, 1],
    [2, 2],
    [3, 3],
    [4, 4]
])

pca = PCA(n_components=1)

X_reduced = pca.fit_transform(X)

print("Original data:")
print(X)

print("Mean:")
print(pca.mean_)

print("Principal component:")
print(pca.components_)

print("Reduced data:")
print(X_reduced)

print("Explained variance ratio:")
print(pca.explained_variance_ratio_)
```

Possible output:

```text
 [2 2]
 [3 3]
 [4 4]]

Reduced data:
[[-2.12132034]
 [-0.70710678]
 [ 0.70710678]
 [ 2.12132034]]

Explained variance ratio:
[1.]
```

Meaning:

```markdown
The 2D data was reduced to 1D.
The first principal component captured almost all variance.
```

# 28. Common Mistakes

```markdown
## Clustering Mistakes

1. Thinking clustering uses labels.
Wrong. Clustering is unsupervised.

2. Thinking K-Means chooses K automatically.
Wrong. Usually we choose K first.

3. Thinking centroid must be a real data point.
Wrong. Centroid can be an average point.

4. Forgetting to update centroids.
K-Means repeats:
assignment → update → assignment → update

5. Confusing single and complete linkage.
Single = smallest pairwise distance
Complete = largest pairwise distance

6. Thinking lower SSE always means best model.
If K is too large, SSE becomes small but clusters may be meaningless.
```

```markdown
## PCA Mistakes

1. Thinking PCA is supervised.
Wrong. PCA is unsupervised.

2. Thinking PCA creates clusters.
Wrong. PCA reduces dimensions.

3. Thinking PCA selects original features only.
Wrong. PCA creates new features called principal components.

4. Forgetting mean normalization.
PCA should use centered data.

5. Forgetting feature scaling when feature ranges are very different.

6. Thinking eigenvector means amount.
Wrong:
eigenvector = direction
eigenvalue = amount of variance

7. Thinking PC1 uses the smallest eigenvalue.
Wrong. PC1 uses the largest eigenvalue.

8. Thinking PCA always improves clustering.
Not always. PCA may remove useful information if too few components are kept.
```
