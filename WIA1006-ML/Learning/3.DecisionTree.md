# Chapter 3 Complete Revision Notes: Decision Tree

## 1. What is a Decision Tree?

A **Decision Tree** is a Machine Learning model that makes predictions by asking questions step by step.

It looks like a tree:

```text
Weather?
├── Sunny
│   └── Humidity?
│       ├── High → No
│       └── Normal → Yes
├── Cloudy → Yes
└── Rainy
    └── Wind?
        ├── Strong → No
        └── Weak → Yes
```

The lecture note defines Decision Tree as a **tree-based classifier** where instances are represented as feature vectors. Nodes test features, branches represent feature values, and leaves specify the final category. 

Simple idea:

```text
Input features → Ask questions → Follow branches → Reach prediction
```

Example:

```text
Weather = Sunny
Humidity = High

Prediction = No
```

---

## 2. Why do we need Decision Trees?

Decision Trees are useful because they are easy to understand and explain.

Instead of using a formula like:

```text
y = mx + c
```

a Decision Tree uses rules like:

```text
IF Weather = Sunny AND Humidity = High
THEN Play = No
```

The lecture says Decision Trees can be rewritten as a set of rules. 

This makes Decision Trees useful when we want explainable predictions.

---

## 3. Main parts of a Decision Tree

The tutorial lists three important node types: **root node**, **decision node**, and **leaf node**. 

| Node type     | Meaning                                  | Example                     |
| ------------- | ---------------------------------------- | --------------------------- |
| Root node     | The first/top node where the tree starts | `Weather?`                  |
| Decision node | Internal node that asks another question | `Humidity?`                 |
| Leaf node     | Final prediction/output                  | `Yes`, `No`, `Pass`, `Fail` |

Diagram:

```text
Weather?                 ← Root node
├── Sunny
│   └── Humidity?        ← Decision node
│       ├── High → No    ← Leaf node
│       └── Normal → Yes ← Leaf node
└── Rainy → No           ← Leaf node
```

---

## 4. Decision Tree Classification vs Regression

Decision Trees can be used for both classification and regression.

The lecture note says classification trees have **discrete class labels** at the leaves, while regression trees allow **real-valued outputs** at the leaves. 

| Type                | Output         | Example                          |
| ------------------- | -------------- | -------------------------------- |
| Classification Tree | Category/class | Yes/No, Pass/Fail, Spam/Not Spam |
| Regression Tree     | Number         | House price, marks, salary       |

For this chapter, we mainly focused on **classification**.

---

## 5. Pure group and mixed group

A **pure group** contains only one class.

```text
Yes, Yes, Yes, Yes
```

This is pure.

A **mixed group** contains different classes.

```text
Yes, No, Yes, No
```

This is mixed.

Simple rule:

```text
Pure group  → low entropy
Mixed group → high entropy
```

The tutorial says mixed classes have high entropy, pure groups have low entropy, and the best split gives the biggest reduction in uncertainty. 

---

## 6. Entropy

Entropy measures how mixed, impure, or uncertain a group is.

For binary classification:

```text
Entropy(S) = -p_yes log2(p_yes) - p_no log2(p_no)
```

Where:

```text
p_yes = number of Yes / total
p_no  = number of No / total
```

The lecture note defines entropy as disorder or impurity and says entropy is `0` when all examples are in one category, and maximum `1` when binary classes are equally mixed. 

---

## 7. Entropy examples

### Example 1: Pure group

```text
Yes, Yes, Yes, Yes
```

```text
p_yes = 4/4 = 1
p_no  = 0/4 = 0
Entropy = 0
```

Meaning:

```text
No confusion.
The group is pure.
```

---

### Example 2: Perfectly mixed group

```text
Yes, Yes, No, No
```

```text
p_yes = 2/4 = 0.5
p_no  = 2/4 = 0.5
```

```text
Entropy = -0.5 log2(0.5) - 0.5 log2(0.5)
Entropy = 1
```

Meaning:

```text
Maximum confusion for binary classification.
```

---

### Example 3: Mostly one class

```text
Yes, Yes, Yes, No
```

```text
p_yes = 3/4 = 0.75
p_no  = 1/4 = 0.25
```

```text
Entropy ≈ 0.811
```

This group is not pure, but it is less mixed than:

```text
Yes, Yes, No, No
```

## 8. Useful entropy values

| Labels             | Entropy |
| ------------------ | ------: |
| Yes, Yes, Yes, Yes |       0 |
| No, No, No, No     |       0 |
| Yes, Yes, Yes, No  |   0.811 |
| Yes, Yes, No, No   |       1 |

Remember:

```text
Entropy = 0 → pure
Entropy = 1 → maximum mixed for binary class
```

## 9. Information Gain

Information Gain measures how much entropy is reduced after splitting.

The lecture says Information Gain is the expected reduction in entropy after splitting on a feature. 

Formula:

```text
Information Gain = Entropy before split - Weighted entropy after split
```

Simple meaning:

```text
Entropy = how messy the data is
Information Gain = how much messiness is removed
```

Higher Information Gain means better split.

---

## 10. Weighted entropy after split

When a feature splits data into groups, each group may have different size.

So we calculate weighted entropy:

```text
Weighted entropy =
(size of group A / total) × entropy(group A)
+
(size of group B / total) × entropy(group B)
```

Example:

```text
Total = 10

Group A = 8 data, entropy = 0.5
Group B = 2 data, entropy = 1.0
```

```text
Weighted entropy = (8/10 × 0.5) + (2/10 × 1.0)
```

A bigger group affects the final entropy more.

---

## 11. Information Gain example

Dataset:

| Student | Study Hours | Passed |
| ------- | ----------- | ------ |
| A       | High        | Yes    |
| B       | High        | Yes    |
| C       | Low         | No     |
| D       | Low         | No     |

Before split:

```text
Passed = Yes, Yes, No, No
Entropy before = 1
```

Split by `Study Hours`:

```text
High → Yes, Yes → Entropy = 0
Low  → No, No   → Entropy = 0
```

Weighted entropy after split:

```text
= (2/4 × 0) + (2/4 × 0)
= 0
```

Information Gain:

```text
IG = 1 - 0
IG = 1
```

So `Study Hours` is a perfect split.

## 12. Choosing the best feature

Decision Tree chooses the feature with the **highest Information Gain**.

Example:

| Feature     | Information Gain |
| ----------- | ---------------: |
| Study Hours |             1.00 |
| Attendance  |             0.00 |

Choose:

```text
Study Hours
```

because it has higher Information Gain.

The tutorial says ID3 chooses the attribute with the highest Information Gain.

## 13. ID3 Algorithm

ID3 is a Decision Tree algorithm.

The tutorial says ID3 is a mathematical algorithm for building a Decision Tree. It uses **Entropy** and **Information Gain** as attribute selection measures. 

ID3 process:

```text
Start with all training data
↓
Calculate entropy
↓
Calculate Information Gain for each feature
↓
Choose feature with highest Information Gain
↓
Split the data
↓
Repeat on each branch
```

Simple definition:

```text
ID3 = builds a Decision Tree by choosing the best feature using Information Gain
```

---

## 14. ID3 stopping conditions

ID3 stops when:

### Case 1: All examples are in one class

```text
Yes, Yes, Yes
```

Return:

```text
Leaf node: Yes
```

### Case 2: No features are left

```text
Labels = Yes, Yes, No
Features left = none
```

Return majority class:

```text
Leaf node: Yes
```

### Case 3: Branch has no examples

If a branch has no data, use the most common class from the current data.

The lecture pseudocode says if all examples are in one category, return a leaf node with that label. If features are empty, return a leaf with the most common label. If a branch has no examples, attach a leaf with the most common category. 

---

## 15. Decision Tree induction pseudocode

Beginner version:

```text
DTree(data, features):

1. If all target answers are the same:
       return that answer as a leaf node.

2. Else if no features are left:
       return the majority target answer.

3. Else:
       calculate Information Gain for every feature.

4. Choose the feature with highest Information Gain.

5. Create a decision node using that feature.

6. For each value of that feature:
       create a branch.

7. Put matching rows into that branch.

8. If the branch has no rows:
       attach a majority-class leaf.

9. Else:
       call DTree again on the smaller branch dataset.

10. Return the completed tree.
```

The lecture shows this as `DTree(examples, features)` returning a tree. 

---

## 16. Recursion in Decision Tree

Decision Tree induction is recursive.

That means:

```text
Build current node
Then build smaller tree for each branch
```

Example:

```text
Weather?
├── Sunny  → build subtree using Humidity and Wind
├── Rainy  → build subtree using Humidity and Wind
└── Cloudy → maybe leaf
```

If `Weather` is already used, the remaining features are:

```text
Humidity, Wind
```

The lecture pseudocode shows this idea using:

```text
features - {F}
```

meaning the selected feature is removed from the next recursive call.

Temperature ≤ 30 → left branch

## 19. How Decision Tree chooses threshold

Process:

```text
1. Sort numerical values.
2. Try possible cut-off points.
3. Split data into two groups.
4. Calculate Information Gain.
5. Choose the threshold with highest Information Gain.
```

Example sorted marks:

```text
30, 35, 40, 45, 55, 60, 65, 70
```

Possible thresholds:

```text
32.5, 37.5, 42.5, 50, 57.5, 62.5, 67.5
```

The best threshold is the one with the highest Information Gain.

## 20. Overfitting in Decision Tree

Overfitting happens when a model performs very well on training data but poorly on unseen test data.

The lecture defines overfitting as a case where one hypothesis has lower error on training data but higher error on independent test data compared to another hypothesis. 

Simple meaning:

```text
Overfitting = memorizing training data too much
```

Example:

```text
Training accuracy = 100%
Test accuracy = 60%
```

This is likely overfitting.

---

## 21. Why Decision Trees overfit easily

Decision Trees can keep splitting until they classify training data perfectly.

Problem:

```text
Perfect training accuracy does not always mean good model.
```

The lecture says a tree that perfectly classifies training data may not generalize well because it may fit noise or make weak decisions near leaves using very little data. 

Common signs:

```text
Tree is too deep
Leaves have very few samples
Training accuracy much higher than test accuracy
```

---

## 22. How to reduce overfitting

Common methods:

```text
1. Limit max_depth
2. Increase min_samples_split
3. Increase min_samples_leaf
4. Use pruning
5. Use validation/cross-validation
6. Remove noisy or useless features
```

Example in Python:

```python
DecisionTreeClassifier(
    max_depth=3,
    min_samples_leaf=5,
    random_state=42
)
```

## 23. Pruning

Pruning means removing unnecessary branches from a Decision Tree.

The tutorial says pruning is the process of removing sub-nodes of a decision node and is the opposite of splitting. It also lists **pre-pruning** and **post-pruning** as two common methods. 

Simple meaning:

```text
Pruning = cut unnecessary branches to reduce overfitting
```

Before pruning:

```text
Weather?
├── Sunny
│   └── Humidity?
│       └── StudentID?
│           ├── 1001 → Yes
│           └── 1002 → No
└── Rainy → No
```

After pruning:

```text
Weather?
├── Sunny
│   └── Humidity? → ...
└── Rainy → No
```

---

## 24. Pre-pruning

Pre-pruning stops the tree early during construction.

Simple meaning:

```text
Pre-pruning = stop early before tree becomes too deep
```

Examples in Python:

```python
DecisionTreeClassifier(max_depth=3)
DecisionTreeClassifier(min_samples_split=10)
DecisionTreeClassifier(min_samples_leaf=5)
```

The lecture says pre-pruning stops tree growth during top-down construction when there is not enough data to make reliable decisions. 

---

## 25. Post-pruning

Post-pruning grows the full tree first, then removes weak branches later.

Simple meaning:

```text
Post-pruning = grow first, cut later
```

In sklearn, one way is:

```python
DecisionTreeClassifier(ccp_alpha=0.01)
```

`ccp_alpha` controls pruning strength.

```text
Small ccp_alpha → less pruning
Large ccp_alpha → more pruning
```

The lecture says post-pruning grows the full tree first, then removes subtrees that do not have enough evidence. 

---

## 26. Pre-pruning vs post-pruning

| Method       | When it happens          | Meaning           |
| ------------ | ------------------------ | ----------------- |
| Pre-pruning  | During tree building     | Stop early        |
| Post-pruning | After full tree is built | Cut weak branches |

Remember:

```text
Pre = before tree becomes too large
Post = after full tree is built
```

## 27. Noisy data

Noisy data means data contains mistakes, unusual values, or inconsistent information.

The lecture says Decision Tree methods have been developed to handle noisy training data, including both class noise and feature noise. 

### Class noise

Target label is wrong.

Example:

| Weather | Humidity | Play |
| ------- | -------- | ---- |
| Sunny   | High     | No   |
| Sunny   | High     | No   |
| Sunny   | High     | Yes  |

The last label may be wrong.

```text
Class noise = wrong target/output value
```

### Feature noise

Input feature value is wrong.

Example:

```text

```

```text
Feature noise = wrong input/attribute value
```

## 29. Important data leakage warning

Wrong way:

```python
df["StudyHours"] = df["StudyHours"].fillna(df["StudyHours"].median())

X_train, X_test, y_train, y_test = train_test_split(...)
```

Problem:

```text
Median was calculated using the whole dataset, including test data.
```

Better way:

```text
1. Split train/test first.
2. Fit imputer on training data.
3. Transform training data.
4. Transform test data using same imputer.
```

Example:

```python
imputer = SimpleImputer(strategy="median")

X_train_filled = imputer.fit_transform(X_train)
X_test_filled = imputer.transform(X_test)
```

## 31. Python example: numerical features only

```python
import pandas as pd

from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeClassifier, export_text
from sklearn.metrics import accuracy_score

data = {
    "StudyHours": [1, 2, 2, 3, 4, 5, 6, 7, 8, 9],
    "Attendance": [40, 50, 55, 60, 65, 75, 80, 85, 90, 95],
    "Passed": ["No", "No", "No", "No", "No", "Yes", "Yes", "Yes", "Yes", "Yes"]
}

df = pd.DataFrame(data)

X = df[["StudyHours", "Attendance"]]
y = df["Passed"]

X_train, X_test, y_train, y_test = train_test_split(
    X,
    y,
    test_size=0.3,
    random_state=42
)

model = DecisionTreeClassifier(
    criterion="entropy",
    max_depth=2,
    random_state=42
)

model.fit(X_train, y_train)

y_pred = model.predict(X_test)

print("Predictions:", y_pred)
print("Actual:", list(y_test))
print("Accuracy:", accuracy_score(y_test, y_pred))

print(export_text(model, feature_names=["StudyHours", "Attendance"]))
```

Possible output:

```text
|--- StudyHours <= 4.50
|   |--- class: No
|--- StudyHours >  4.50
|   |--- class: Yes
```

Meaning:

```text
If StudyHours ≤ 4.5 → predict No
If StudyHours > 4.5 → predict Yes
```

## 32. Python example: categorical + numerical features

```python
import pandas as pd

from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeClassifier
from sklearn.preprocessing import OneHotEncoder
from sklearn.compose import ColumnTransformer
from sklearn.pipeline import Pipeline
from sklearn.metrics import accuracy_score, confusion_matrix, classification_report

data = {
    "Weather": [
        "Sunny", "Sunny", "Cloudy", "Rainy", "Rainy",
        "Rainy", "Cloudy", "Sunny", "Sunny", "Rainy",
        "Sunny", "Cloudy", "Cloudy", "Rainy"
    ],
    "Humidity": [
        "High", "High", "High", "High", "Normal",
        "Normal", "Normal", "High", "Normal", "Normal",
        "Normal", "High", "Normal", "High"
    ],
    "Wind": [
        "Weak", "Strong", "Weak", "Weak", "Weak",
        "Strong", "Strong", "Weak", "Weak", "Weak",
        "Strong", "Strong", "Weak", "Strong"
    ],
    "Temperature": [
        33, 35, 30, 28, 27,
        29, 26, 34, 31, 25,
        32, 30, 27, 29
    ],
    "Play": [
        "No", "No", "Yes", "Yes", "Yes",
        "No", "Yes", "No", "Yes", "Yes",
        "Yes", "Yes", "Yes", "No"
    ]
}

df = pd.DataFrame(data)

X = df[["Weather", "Humidity", "Wind", "Temperature"]]
y = df["Play"]

X_train, X_test, y_train, y_test = train_test_split(
    X,
    y,
    test_size=0.3,
    random_state=42
)

categorical_features = ["Weather", "Humidity", "Wind"]
numeric_features = ["Temperature"]

preprocessor = ColumnTransformer(
    transformers=[
        ("cat", OneHotEncoder(handle_unknown="ignore"), categorical_features),
        ("num", "passthrough", numeric_features)
    ]
)

model = Pipeline(
    steps=[
        ("preprocessor", preprocessor),
        ("classifier", DecisionTreeClassifier(
            criterion="entropy",
            max_depth=3,
            random_state=42
        ))
    ]
)

model.fit(X_train, y_train)

y_pred = model.predict(X_test)

print("Predictions:", y_pred)
print("Actual values:", list(y_test))
print("Accuracy:", accuracy_score(y_test, y_pred))
print("Confusion Matrix:")
print(confusion_matrix(y_test, y_pred))
print("Classification Report:")
print(classification_report(y_test, y_pred))
```

## 33. Why use OneHotEncoder?

Categorical features like:

```text
Sunny, Rainy, Cloudy
```

must be converted into numbers.

Use:

```python
OneHotEncoder(handle_unknown="ignore")
```

Example:

```text
Weather = Sunny
```

becomes:

```text
Weather_Sunny = 1
Weather_Rainy = 0
Weather_Cloudy = 0
```

Avoid using fake ordering like:

```text
Sunny = 0
Rainy = 1
Cloudy = 2
```

because it may imply an order that does not exist.

## 36. Common mistakes

### Mistake 1: Confusing entropy and Information Gain

```text
Entropy = how mixed the group is
Information Gain = how much entropy is reduced
```

### Mistake 2: Choosing lowest Information Gain

Wrong:

```text
Choose IG = 0.1
```

Correct:

```text
Choose highest IG
```

### Mistake 3: Thinking high entropy is good

Wrong.

```text
High entropy = messy group
Low entropy = pure group
```

### Mistake 4: Splitting pure groups again

If a branch has:

```text
Yes, Yes, Yes
```

stop and make:

```text
Leaf = Yes
```

### Mistake 5: Letting tree grow too deep

This may cause overfitting.

Use:

```python
max_depth
min_samples_leaf
pruning
```

### Mistake 6: Using raw text features in sklearn without encoding

Use OneHotEncoder for categorical input features.

### Mistake 7: Fitting preprocessing on test data

Fit preprocessing only on training data, then transform test data.

## 38. Mini formula sheet

### Entropy

```text
Entropy(S) = -p_yes log2(p_yes) - p_no log2(p_no)
```

### Multi-class entropy

```text
Entropy(S) = Σ -pi log2(pi)
```

### Information Gain

```text
IG(S, Feature) = Entropy(S) - Weighted Entropy After Split
```

### Weighted entropy

```text
Weighted Entropy =
Σ (size of subset / size of original set) × Entropy(subset)
```
